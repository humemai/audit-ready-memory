# Reuse and citation

## Checklist

- [ ] **License.** The code, the documentation, and the benchmark data are under the
  [MIT license](https://github.com/humemai/audit-ready-memory/blob/main/LICENSE). Keep the copyright
  notice and the license text in copies.
- [ ] **Dependencies.** ArcadeDB and the other packages have their own licenses. Check them for your
  use.
- [ ] **Logos.** The HumemAI and SIDN Fund names and logos are not part of the license. Remove them
  from your own version of the demo.
- [ ] **Data.** The benchmark data and the demo examples are made up and contain no personal data.
  Data you add is your responsibility.
- [ ] **Limits.** Pass on the [limitations](limitations.md) to your own users, above all that deletion
  does not erase.
- [ ] **Credit.** Cite the project as below.

## Citation

The repository has a
[`CITATION.cff`](https://github.com/humemai/audit-ready-memory/blob/main/CITATION.cff) file, which
GitHub turns into a ready-made reference under "Cite this repository". Name the version or commit you
used.
